# Iftar Invitation Manager, Polynomial Operations, Sorted Linked List & Sorting Algorithms in C++

## Overview
This repository contains C++ solutions for four distinct programming problems:

1. **Iftar Invitation Manager** - A system to manage Iftar invitations using Object-Oriented Programming.
2. **Polynomial Operations Using Pointers** - A program for performing addition and subtraction on dynamically allocated polynomials.
3. **Sorted Linked List** - A linked list implementation that maintains sorted order using insertion sort logic.
4. **Sorting Algorithms** - An interactive sorting system implementing nine different sorting algorithms with execution time measurement.

## Problem Descriptions

### 1. Iftar Invitation Manager
**Objective:**
- Store and manage invitations for Iftar gatherings.
- Provide functionalities to add, update, and display guests.
- Sort guest lists and send reminders.

**Key Features:**
- `Guest` class with attributes: name, contact, and invitation date.
- `IftarManager` class for handling multiple guests.
- Methods for adding, updating, displaying, and sorting guest lists.
- Functionality to send reminders.

**Implementation Details:**
- Uses classes and objects for structured programming.
- Sorting is implemented using a sorting algorithm.
- Test cases cover all functionalities.

### 2. Polynomial Operations Using Pointers
**Objective:**
- Perform polynomial addition and subtraction using dynamic memory allocation.

**Key Features:**
- Accepts polynomials dynamically.
- Displays polynomials in a readable format.
- Supports addition and subtraction operations.

**Implementation Details:**
- Uses pointers for dynamic memory allocation.
- Provides structured input and output formatting.
- Includes test cases for correctness verification.

### 3. Sorted Linked List
**Objective:**
- Implement a linked list that maintains sorted order during insertion.
- Provide functionalities for insertion, deletion, and indexing.

**Key Features:**
- `insert(n)`: Inserts an element while maintaining sorted order.
- `remove(n)`: Removes an element by index.
- Overloaded operators:
  - `<<` for displaying the list.
  - `[]` for accessing elements by index.
- Proper memory management.

**Implementation Details:**
- Uses a linked list structure with proper memory handling.
- Provides exception handling for out-of-bounds access.
- Includes test cases for each function.

### 4. Sorting Algorithms
**Objective:**
- Implement and compare various sorting algorithms.
- Provide an interactive menu for selecting sorting methods.

**Sorting Algorithms Implemented:**
1. Insertion Sort
2. Selection Sort
3. Bubble Sort
4. Shell Sort
5. Merge Sort
6. Quick Sort
7. Count Sort (Integers only)
8. Radix Sort (Integers only)
9. Bucket Sort

**Key Features:**
- Uses templates to support multiple data types.
- Displays sorting process step-by-step.
- Measures and displays execution time.

**Implementation Details:**
- Utilizes an interactive menu for user input.
- Provides real-time tracking of sorting progress.
- Includes test cases to verify sorting correctness.
